SHŌGEN — SPÉCIFICATION LOGO · v1.0 · validé pour implémentation
Shōgen Comptez vos sources. Vraiment.

Direction retenue : « Amont commun » (référence interne 3B). Symbole : trois sources indépendantes convergeant vers un agrégateur unique. Ce document fixe la construction, les couleurs, la typo et les règles d'usage pour l'implémentation.

1. Symbole — construction

Viewbox : 0 0 64 64. Trois nœuds sources aux coordonnées (14,16), (32,10), (50,16) — rayon 6px, couleur d'encre pleine. Trois traits (largeur 3px, extrémités arrondies) convergent vers le nœud récepteur (32,50) — rayon 8px, unique élément en corail #FF6B4A.

Zone de protection minimale : un rayon de nœud source (6px à l'échelle native) tout autour du symbole. Ne jamais recadrer les traits.

Taille minimale : 20px de haut pour le symbole seul, 24px pour le lockup complet (symbole + logotype). Sous cette taille, utiliser l'icône simplifiée (section 4).

2. Animation (spec d'implémentation)

Durée de boucle2.6s, ease-in-out, infinie
Trait gauchestroke-dashoffset 38→0, delay 0s
Trait centralstroke-dashoffset 38→0, delay 0.15s
Trait droitstroke-dashoffset 38→0, delay 0.3s
Nœud récepteurpulse scale 1→1.35→1 à t=0.9s (à l'arrivée des traits)
Reposversion statique (ci-dessus) pour favicon, print, contextes sans animation

Usage : hero/loader/splash uniquement. Jamais en boucle dans une UI dense (nav, listes) — utiliser la version statique.

Règle : le corail n'apparaît QUE sur le nœud récepteur. Jamais utilisé ailleurs dans l'UI comme couleur décorative — il doit rester associé à « ce qui reçoit/agrège ».

4. Fond clair / fond sombre

Shōgen FOND CLAIR — logotype #0E3B34
Shōgen FOND SOMBRE — logotype #FFFFFF

Le corail du nœud récepteur ne change JAMAIS entre les deux fonds — c'est le seul élément à couleur fixe du système.

5. Icône / favicon

64 / 32 / 16 px — coin arrondi 22% de la taille, fond #0E3B34, symbole statique (pas d'animation)

6. Typographie

Logotype : Sora 700, letter-spacing -0.03em.

Accroche / UI : Sora 500 (accroche), Sora 400 (texte courant).

Mono (specs, data, code) : IBM Plex Mono ou JetBrains Mono 400/500.

Une seule famille sans-serif (Sora) pour toute l'UI produit — pas de serif, pas de deuxième sans dans l'identité.

7. À ne pas faire

  • Ne pas recolorer les trois nœuds sources ni les traits — seul le nœud récepteur est en corail.
  • Ne pas faire tourner, dupliquer ou refléter le symbole.
  • Ne pas placer le symbole sur une photo ou un fond texturé sans plaque de couleur pleine derrière.
  • Ne pas animer le symbole dans une UI dense (nav, tableaux, listes) — version statique uniquement.
  • Ne pas utiliser le corail comme couleur d'accent générale dans le produit (boutons, liens, etc.).
